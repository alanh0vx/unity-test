# Interface fonts

ROOTBREACH uses Doom-inspired block lettering and beveled status digits, rather than a copy of Doom's game assets.

- **Russo One** — Jovanny Lemonad. Display lettering and status digits. SIL Open Font License. Source: https://github.com/google/fonts/tree/main/ofl/russoone
- **Barlow Condensed SemiBold** — The Barlow Project Authors / Jeremy Tribby. HUD labels and supporting text. SIL Open Font License. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed

The original license files are bundled beside the TTF files. Both fonts are embedded locally; the game does not download fonts at runtime.
